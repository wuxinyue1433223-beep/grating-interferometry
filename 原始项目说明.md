# VisionShell

A modular WPF framework for device integration and vision control applications.

## Structure
- **Core**: Shared interfaces and abstractions (bin/<Config>/app).
- **App**: WPF Shell host (bin/<Config>/app).
- **Features**: Functional modules (e.g., OptiTrack) referenced by App.
- **Plugins**: Device drivers loaded via `plugin.json` (bin/<Config>/app/plugins/<device-name>).
